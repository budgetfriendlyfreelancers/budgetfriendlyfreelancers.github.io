## 🎨 Design System & Consistency

### Typography
- **Headings:** Syne font (800 weight for h1/h2, 700 for h3/h4)
- **Body:** DM Sans (400 weight)
- **Responsive:** Headline sizes use `clamp()` for fluid scaling

### Spacing
- **Section Padding:** 4–5rem top/bottom
- **Container:** Bootstrap `.container` (max-width responsive)
- **Gap (grid items):** 1.5–2rem

### Interactive Elements
- **Hover States:** All buttons get slight elevation (translateY -2px) + shadow
- **Link Animations:** Arrows animate on hover (gap increases)
- **Card Hovers:** Cards lift up, shadow deepens, border color changes

### Mobile-First Approach
- **Navbar:** Hamburger menu on < lg breakpoint
- **Grids:** `grid-template-columns: repeat(auto-fit, minmax(200–320px, 1fr))`
- **Typography:** Responsive font sizes using `clamp()`
- **Buttons:** Full-width on mobile, auto-width on desktop

### Fade-In Animation
- **Trigger:** Intersection Observer (threshold: 0.1–0.12)
- **Initial:** opacity 0, translateY 24px
- **Active:** opacity 1, translateY 0
- **Transition:** 0.6s ease

## 📱 Mobile Considerations

### Responsive Breakpoints (Bootstrap)
- **xs:** < 576px (mobile)
- **sm:** ≥ 576px (small tablet)
- **md:** ≥ 768px (tablet)
- **lg:** ≥ 992px (desktop)
- **xl:** ≥ 1200px (large desktop)

### Key Mobile Adaptations
1. **Navigation:** Collapses into hamburger menu
2. **Hero:** Single column layout, centered content
3. **Grids:** Stack to single column or 2 columns on mobile
4. **Testimonials:** Show 1 card at a time (consider carousel on mobile)
5. **Process Timeline:** Vertical line hides, becomes numbered list with left border
6. **WhatsApp Button:** Fixed position remains but may adjust padding on very small screens
